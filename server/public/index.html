Regel für Klassenkürzel

Format: [Klassenstufe][a/b/c...][H/R]
• Stufe: Jahrgang (z. B. 5, 6, 7, 8, 9, 10)
• Zweig: immer klein (a, b, c, d, ...)
• Schulform: immer groß am Ende (H für Hauptschule, R für Realschule)

Beispiele: 9aR, 8aR, 7bH, 10cR
